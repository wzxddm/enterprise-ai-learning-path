# 项目作品集

学习过程中至少完成下面四个项目。每个项目都应能独立运行、评测和复现。

## 项目一：LLM API 实验室

覆盖阶段：1

- 流式输出。
- 结构化输出。
- Tool Calling。
- Prompt 和采样参数对比。
- 延迟与 Token 统计。

## 项目二：技术文档 RAG 助手

覆盖阶段：4、7

- 文档解析与增量索引。
- 多种 Chunk 策略。
- 混合检索和重排序。
- 原文引用和无答案拒答。
- 固定评测集和回归报告。

## 项目三：代码仓库 Agent

覆盖阶段：5、7

- 代码搜索和文件读取。
- 测试执行和错误分析。
- 状态管理、超时、重试和终止条件。
- 人工确认和权限边界。
- 完整工具调用日志。

## 项目四：模型微调与部署

覆盖阶段：6、7

- 数据集清洗与版本管理。
- LoRA / QLoRA 微调。
- 微调前后固定评测。
- LMDeploy 服务部署。
- 并发压测和显存分析。

## 每个项目的交付清单

- [ ] README：背景、目标、架构和运行方式。
- [ ] 架构图和关键数据流。
- [ ] 可复现的配置与依赖。
- [ ] 自动化测试或评测脚本。
- [ ] 质量、性能和成本数据。
- [ ] 失败案例。
- [ ] 已知限制与下一步计划。

## 推荐仓库结构

```text
project-name/
├── README.md
├── configs/
├── data/
├── docs/
├── evals/
```
