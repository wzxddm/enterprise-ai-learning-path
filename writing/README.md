# 知乎专栏写作系统

## 专栏定位

推荐名称：

> 从程序员到企业 AI 应用工程师：20 周生产落地实战

备用名称：

- 大模型生产实践：从 Demo 到业务价值
- 企业 AI 应用工程师成长手册
- 不止 Prompt：大模型落地的工程细节

目标读者：有开发经验，想进入 AI 应用工程或负责企业 AI 落地的人。

## 专栏承诺

每篇文章都回答六件事：

1. 技术位于生产系统的什么环节？
2. 能解决什么业务问题，不能解决什么？
3. 当前成熟度、瓶颈和争议是什么？
4. 如何通过可复现实验证明效果？
5. 上线需要哪些评测、安全、成本和兜底措施？
6. 未来可能如何发展，今天应该积累什么长期资产？

## 专栏差异化

- 不写 API 搬运文。
- 不只展示成功 Demo，固定记录失败案例。
- 不用模型排行榜代替业务测试集。
- 不把行业报告观点伪装成自己的实验结论。
- 每阶段至少有一个可运行项目和一份评测报告。
- 从业务指标、生产架构和上线决策角度写技术。

## 内容质量门槛

一篇文章至少包含以下四类证据中的三类：

- 一手文档、论文或行业报告。
- 自己的实验数据。
- 可运行代码或配置。
- 真实或明确标注为假设的业务案例。

文章结尾必须写：已知限制、仍未解决的问题、下一步实验。
