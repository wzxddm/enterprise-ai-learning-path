# 第一阶段知乎写作计划

第一阶段只要求两篇高质量文章。宁可提供实验数据、失败案例和架构图，也不要每天发布浅层学习流水账。

## 文章一：企业真正需要的不是聊天机器人，而是可控的 AI 业务闭环

### 核心命题

模型能力已经足够令人惊艳，但企业落地的主要矛盾是业务选择、系统集成、评测、治理和 ROI，而不是再写一个聊天页面。

### 建议结构

1. 从一个“演示很好、上线失败”的假想案例切入。
2. 给出 2026 年企业采用与规模化数据。
3. 解释企业 AI 技术地图。
4. 对比 Demo 和生产系统。
5. 给出选择首个 AI 场景的评分表。
6. 展示自己的工单项目范围与验收门槛。
7. 写出目前仍未解决的问题。

### 必须包含

- Stanford 与 Deloitte 原始报告链接和口径。
- 一张自己绘制的生产架构图。
- 至少一个“为什么不使用 AI”的反例。
- 区分报告事实、工程判断和个人预测。

## 文章二：我用工单分诊实验验证了 LLM 的三个生产边界

### 核心命题

结构化输出解决不了语义错误；Temperature 低不等于绝对确定；模型效果必须与规则基线、错误成本和人工兜底一起评价。

### 建议结构

1. 业务问题和人工基线。
2. 数据集如何构造，哪些数据有偏差。
3. 规则、纯 LLM、混合方案的设计。
4. 输出 Schema 和业务校验。
5. 质量、延迟、成本结果表。
6. 三类最有价值的失败案例。
7. Prompt Injection 与敏感数据处理。
8. Go / No-Go 上线结论。
9. 下一阶段准备解决的问题。

### 禁止出现

- 只展示几条成功回答。
- 没有测试集规模和指标定义的“准确率很高”。
- 只比较模型价格，不计算错误与人工成本。
- 把合成数据实验包装成真实企业生产结论。
