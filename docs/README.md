# AI Path 学习平台

这是学习路线的静态网页版本，无需安装依赖或构建。

## 本地运行

在项目根目录执行：

```bash
python3 -m http.server 4173
```

浏览器访问：

```text
http://127.0.0.1:4173/docs/
```

## 功能

- 7 个阶段、42 个可打卡任务。
- 22 份按阶段、难度和产出排序的中文资料。
- 第一阶段 4 个可执行学习单元，包含中文章节、练习数据、参考答案和验收标准。
- 总体进度和阶段进度。
- 每日打卡、连续学习天数和学习时长。
- 第一阶段生产判断测验和答案解析。
- 项目作品集与 14 篇知乎文章状态管理。
- JSON 数据导出和导入。
- 桌面端与移动端响应式布局。

## 数据存储

进度使用浏览器 `localStorage` 保存，不上传到服务器。更换浏览器、设备或域名之前，请在“学习记录”页面导出 JSON 备份。

## GitHub Pages

将本项目推送到独立 GitHub 仓库后，在仓库设置中选择：

```text
Settings → Pages → Deploy from a branch
Branch: main
Folder: /docs
```

保存后即可通过 GitHub Pages 地址访问。
